## ⚡ Quick Start (Copy & Paste)

### 1. Setup Project
```bash
# Go to your project directory
cd social-voice-blog

# Install dependencies
npm install

# Copy environment template
cp .env.example .env
```

### 2. Setup MongoDB (Free)
Go to: https://www.mongodb.com/cloud/atlas
- Create free account
- Create M0 Cluster
- Get connection string
- Paste into .env file

### 3. Run Locally
```bash
npm start
```

That's it! Visit http://localhost:5000/api/health

See **QUICKSTART.md** for detailed instructions.

## 📝 Quick Glossary

- **npm** - Package manager (like an app store for code)
- **Node.js** - JavaScript runtime (lets you run JavaScript on your computer)
- **Express** - Web framework (handles HTTP requests)
- **MongoDB** - Database (stores your blog posts)
- **Render** - Cloud hosting (makes your blog available 24/7)
- **API** - Interface to get/send data to your backend
- **JWT** - Authentication tokens (secure login)
- **CORS** - Cross-origin requests (frontend talks to backend)
